OWASP Top 10 Security Scan

Runs the OWASP Top 10 checker against a target you are authorized to test. Every probe passes a scope gate first: by default only the host you type is contacted, and intrusive (state-changing) probes stay off until you turn them on. The passive (read-only) check family is on by default. A category whose probes never reached the server is reported NOT TESTED, never PASS.

      Pentest (offensive scan)

      Runs the offensive pentest checker against a target you are authorized to test. It covers the OWASP Top 10 (A01–A10) plus intrusive families: CRLF injection, SQL injection (boolean and time-based), path traversal, SSRF indicators and write-method probes (PUT/DELETE).

      Every probe passes a scope gate first: by default only the host you type is contacted, and intrusive probes stay off until you turn them on and an authorization ticket is active for the target. A category whose probes never reached the server is reported NOT TESTED, never PASS.

          Site Crawler (open pages)

          Crawls the target like a spider: follows <a href> links and <form> actions, then lists every endpoint discovered (URL, method, parameters, where found).

          By default only the host you type is crawled — offsite links are skipped and redirect hops stay on the original host. Pass Offsite to allow following links to other hosts. Every hop passes the same scope gate the scanner uses.

            HTTP Fuzzer

            Coverage-guided HTTP fuzzer: mutates paths, query params, headers and bodies, then reports responses that differ from the baseline (new status codes, bodies, headers, 5xx, auth boundaries, slow responses).

            Every mutation passes the scope gate. Intrusive mutations (write methods, traversal, injection-ish strings) stay off unless enabled and authorized.
